Safe-Seller-Keep-Alive

Stealth Marketplace Session Manager (Manifest V3)
🏷️ Release v1.3.0 (Public)
⚡ Live GitHub Sync...

Background browser extension for Microsoft Edge and Google Chrome that keeps marketplace seller accounts (G2G & U7BUY) active at randomized intervals without stealing window focus.

  • Randomized Jitter Engine: Uses chrome.alarms (600s–1000s randomized intervals) to mimic natural human activity in a single background tab.
  • Hardware Wake-Lock & Auto-Recovery: Prevents Windows S0 Modern Standby sleep via chrome.power and auto-recovers expired timers after PC restarts.
  • Cloudflare & Logout Safeguard: Inspects tab titles/URLs prior to refresh and automatically pauses + alerts the user if a security challenge or login redirect occurs.
JavaScript (ES6+) Manifest V3 Service Workers chrome.alarms & chrome.power Edge / Chrome Extension
